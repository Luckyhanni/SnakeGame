\# SnakeGame (C# Console, .NET 8)



Kleines Konsolen-Snake im Rahmen der Softwaretechnik-Abgabe. Fokus: einfache, saubere Architektur mit Unit-Tests.

## Voraussetzungen

Um das Projekt auszuführen, wird **.NET 8.0 SDK** benötigt.  

\## Ausführen

```bash

dotnet build

dotnet run --project SnakeGame

dotnet test
